## 🩺 Featured — HERO (한림대의료원 의료데이터 경진대회)

**마약류·남용위험 약물 부작용(ADE)을 투약 시점에 예측해, ‘선발생 후조치’ → ‘선조치(pre-emptive)’로 전환하는 처방 체계.**

> 혈당·INR 같은 정형 모니터링 지표가 없는 오피오이드·NSAID·메토클로프라미드에 대해, **투약 전 정보만으로 부작용별 발생확률을 예측**한다.

**핵심 기여**
- 🎭 **오염 마스크 (contamination mask)** — EHR에서 보정약에 ‘가려진’ 부작용 신호를 분리해 왜곡 없이 학습
- 📊 **보정된 절대 확률 위험 등급** — isotonic 보정(예측 20% = 실제 20%) + 5단계 등급으로 임상 바로 적용
- 🔒 **엄격한 평가** — 잠금 테스트셋 · 층화 5-fold · 부트스트랩 CI → 과적합 없음, AUROC **0.82 ~ 0.95**

**타임라인 (Milestones)**

| 단계 | 내용 |
|------|------|
| **M1 · 데이터·약물 선정** | OMOP CDM 7개 테이블 프로파일링, 대상 약물 5종 확정 |
| **M2 · EDA** | 부작용 오염/소외 2분류, 유병 가중 위험특징, 용량-반응 분석 (figure 1~11) |
| **M3 · 모델 데이터** | 무손실 입력 테이블 구축 |
| **M4 · Model 1** | 약물별 MLP · 오염 마스크 · 잠금 테스트셋 · isotonic 보정 · 위험 등급 |
| **M5 · 평가** | AUROC 0.82~0.95 · 과적합 없음 · 등급별 실제 발생률 단조 증가 |
| **M6 · 보고서** | 최종보고서(EDA · 모델 · 평가 · 의의) 작성 |

<sub>※ 환자 데이터(OMOP CDM)는 개인정보 보호를 위해 비공개 — 코드·집계 결과·보고서만 포함.</sub>
